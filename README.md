## Descripción del proyecto
Este proyecto busca analizar el precio comercial de los carros en Colombia en el pasado, evaluando diversas variables y las relaciones entre ellas; para después predecir la depresiación y el valor de un vehiculo determinado. 

Este es un proyecto viable para un científico de datos, el cual debe tomar una gran gran cantidad de datos para analizar las posibles relaciones entre cada captura y las variables entre ellas, para después utilizar dichas relaciones para predecir un valor futuro y desconocido. 

## Problema
El precio comercial de los carros disminuye conforme para el tiempo. Sin emabrgo, el precio cada vahiuclo parece tener un comportamiento diferente y único, haciendo así que el valor futuro de un carro específico sea una incertidumbre. 

## Objetivos: 
### Objetivo general
Generar un modelo que sea capaz de predecir el valor comercial de carro en el futuro. 

### Objetivos específicos 
- Recolectar datos de diferentes fuentes

- Intregrar los datos de las ddiferentes fuentes
- Determinar el mejor algoritmo para usar
- Ejectuar el algoritmo para analizar los datos
- Entrenar el algoritmo
- Probar los resutlados del algoritmo
